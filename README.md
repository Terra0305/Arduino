# 아두이노 수업 코드 공유

수업 중 학생이 선생님이 준비한 코드를 **버튼 한 번으로 복사**해서 Arduino IDE에 붙여넣고,
막혔을 때는 **자기 코드를 그대로 선생님에게 보내는** 아주 단순한 웹앱입니다.

- 학생 회원가입·로그인·개인정보 수집 없음 (자리 번호만 브라우저에 저장)
- 설치할 패키지 없음 — Node.js 22 이상만 있으면 바로 실행
- 데이터는 `data/app.db` (SQLite) 파일 하나에 저장

## 실행

```bash
ADMIN_PASSWORD=원하는비밀번호 npm start
```

| 주소 | 용도 |
| --- | --- |
| http://localhost:3000/ | 학생 화면 (오늘의 수업) |
| http://localhost:3000/admin | 선생님(관리자) |

처음 실행하면 예시 수업 "LCD에 글자 띄우기"가 하나 들어 있습니다.

### 학생 노트북에서 접속하기

선생님 노트북에서 서버를 켜고, 같은 Wi-Fi에 있는 학생들은 선생님 노트북의 IP로 접속합니다.

```bash
ipconfig getifaddr en0     # macOS: 내 IP 확인
```

학생 안내: `http://192.168.0.10:3000` 처럼 칠판에 적어 주세요.

## 환경 변수

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `ADMIN_PASSWORD` | `arduino` | 관리자 비밀번호. **꼭 바꿔주세요.** |
| `PORT` | `3000` | 서버 포트 |
| `DATA_DIR` | `./data` | DB와 세션 키를 저장할 폴더 |
| `SESSION_SECRET` | 자동 생성 | 로그인 쿠키 서명 키 (`data/secret.key`에 보관) |

## 선생님이 하는 일

1. `/admin`에서 비밀번호로 로그인
2. **새 수업 만들기** — 제목, 설명, Arduino 코드, 준비물(한 줄에 하나), 연결 방법(글/그림), 한 줄 공지 입력
3. **현재 수업으로 지정** — 학생들이 새로고침하면 이 수업이 바로 보입니다
4. 학생이 보낸 코드는 관리자 메인의 **학생 질문**에 최신순으로 쌓입니다 (20초마다 자동 새로고침)
5. 코드를 확인했으면 **✅ 확인 완료** — 목록에서 흐리게 내려갑니다

## 학생이 하는 일

사이트 열기 → **📋 코드 복사하기** → Arduino IDE에서 `Ctrl + V` → 업로드.

문제가 생기면 **🙋 선생님, 안 돼요** → 자리 번호 + 코드 붙여넣기 → 보내기.
자리 번호는 브라우저에 기억되므로 두 번째부터는 그냥 코드만 붙여넣으면 됩니다.

## 폴더 구조

```
server.js            HTTP 서버와 라우팅
src/db.js            SQLite 스키마와 조회/저장 함수
src/http.js          요청/응답 도우미 (HTML 이스케이프, 본문 읽기, 쿠키)
src/auth.js          관리자 비밀번호와 로그인 쿠키
src/highlight.js     Arduino(C++) 문법 강조
src/views/           화면 (layout / student / admin)
public/style.css     스타일 — 큰 글씨, 큰 버튼
public/app.js        코드 복사, 자리 번호 저장, 그림 업로드
data/                SQLite DB (git에 올리지 않음)
```

## 백업과 초기화

- 백업: `data/app.db` 파일을 복사해 두면 됩니다.
- 전부 초기화: 서버를 끄고 `data/` 폴더를 지운 뒤 다시 실행하면 예시 수업만 남은 상태로 시작합니다.

## 알아두면 좋은 점

- 학생 화면은 `http://` 로 접속해도 복사가 되도록 예전 방식(`execCommand`)으로 자동 대체합니다.
  그래도 실패하면 코드 전체를 자동으로 선택해 주므로 `Ctrl + C`로 복사할 수 있습니다.
- 연결 방법 그림은 업로드할 때 브라우저에서 가로세로 1600px 이하로 줄여 DB에 함께 저장합니다.
- 로그인 실패가 5분 안에 8번을 넘으면 그 IP의 로그인 시도를 잠시 막습니다.
